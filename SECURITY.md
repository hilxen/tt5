# Security Policy

## Reporting a vulnerability

Please do not report security issues in public issues or discussions.

Use GitHub's private vulnerability reporting instead:
[Report a vulnerability](https://github.com/hilxen/tt5/security/advisories/new).
You can also email hilxenn@gmail.com.

You will get a reply within a few days. Fixes are released in the next App Store update.

## Supported versions

Only the latest App Store version and the `main` branch receive fixes.
